# PERSPECT

Code and data for **"From Reading Histories to Personalized Summaries: An Evaluation Corpus for News Summarization"**.

PERSPECT pairs 9,823 user–article pairs from DT-PENS with interpretable user interest
profiles, derived from real reading histories, and with multi-sentence personalized
summaries generated by Gemini 3.5 Flash. This repository contains the code to rebuild
the corpus, evaluate it and reproduce the benchmark.

## Installation

```bash
pip install -r requirements.txt
export PYTHONPATH=src
```

Download PENS and DT-PENS as described in [`data/README.md`](data/README.md).

## Reproducing the paper

Run the steps in order. Every step is resumable: if it stops, run the same command again.

**1. Build the user profiles and user–article pairs (Section 3.1)**
```bash
python -m perspect.data.build_profiles
```

**2. Generate the summaries (Sections 3.2, 4.2 and 4.4)**
```bash
export GEMINI_API_KEY="your-key"   # never put the key in the code
python -m perspect.generation.generate --mode personalized   # PERSPECT corpus
python -m perspect.generation.generate --mode generic        # non-personalized baseline
python -m perspect.generation.generate --mode headline       # headline-conditioned (Sec. 4.4)
```
Use `--limit 5` for a quick test. To get a CSV without the prompt column:
```bash
python -m perspect.generation.export_csv --input data/perspect/perspect.jsonl --output data/perspect/perspect.csv
```

**3. Evaluate the corpus (Sections 4.1 and 4.2)**
```bash
# G-Eval (Tables 2 and 5)
python -m perspect.evaluation.geval --summaries data/perspect/perspect.jsonl --output results/geval_personalized
python -m perspect.evaluation.geval --summaries data/perspect/headline.jsonl --output results/geval_headline

# Personalization judge (Tables 3 and 6)
python -m perspect.evaluation.personalization_judge --summaries data/perspect/perspect.jsonl --output results/judge_personalized
python -m perspect.evaluation.personalization_judge --summaries data/perspect/generic.jsonl  --output results/judge_generic
python -m perspect.evaluation.personalization_judge --summaries data/perspect/headline.jsonl --output results/judge_headline
```

**4. Benchmark (Section 4.3, Table 4)**
```bash
python -m perspect.baselines.bart_pegasus --model bart
python -m perspect.baselines.bart_pegasus --model pegasus
python -m perspect.baselines.ctrlsum
python -m perspect.baselines.bart_ft
python -m perspect.baselines.tag_models --model bart
python -m perspect.baselines.tag_models --model pegasus
python -m perspect.baselines.llms --llm mistral-7b
python -m perspect.baselines.llms --llm llama3-8b
python -m perspect.baselines.llms --llm qwen3-8b

# metrics for each output file
python -m perspect.evaluation.metrics --predictions results/outputs/bart.jsonl --name BART
```
See [`src/perspect/baselines/README.md`](src/perspect/baselines/README.md) for the checkpoints.

**5. Corpus statistics (Table 1)**
```bash
python -m perspect.analysis.stats
```

## Models and parameters

All parameters are in `src/perspect/config.py` (Table 7 of the paper). The open LLMs run
locally with Hugging Face `transformers` by default; add `--backend openai --base_url ...`
to use a vLLM or Ollama server instead.
